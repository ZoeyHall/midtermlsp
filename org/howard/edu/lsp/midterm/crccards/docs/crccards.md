# CRC Card Explanation – Library Lending System

Library collaborates with Book because one of Library's responsibilities is to "coordinate borrowing/returning," which requires it to locate a Book and ask that Book to change its own state. Book has no collaborators because its responsibilities (store book information, maintain availability, validate borrowing/returning, provide book details) are self-contained, and it should not know that a Library exists; this keeps the dependency one-directional and lets a standalone Book work on its own. Library enforces the three-book borrowing limit because the limit depends on how many books are borrowed across the whole collection, which is knowledge only Library has, whereas a single Book only knows its own availability. This matches the CRC split: Library "enforces borrowing limit" at the collection level, and Book "validates borrowing/returning" at the individual level. Library checks the limit before delegating, so a rejected borrow leaves every Book unchanged.
